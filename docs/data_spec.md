# 数据与提交规范

统计核验日期：2026-09-12；文档整理及划分哈希复核：2026-09-16。本文只维护数据事实，操作见 `setup.md`，模型代码见 `model.md`。官方依据为赛题PDF和数据 `Label.txt`。

## 1. 数据目录与固定划分

| 目录 | 内容与数量 |
|---|---|
| `data/train/images`、`masks` | 默认训练5596张图像与同名mask |
| `data/val/images`、`masks` | 默认验证1400张图像与同名mask |
| `data/test/images` | 官方测试集1的500张无标签图像 |
| `data/splits/folds.csv` | 全部6996张官方训练图像的fold归属 |
| `data/splits/fold_*_train.txt`、`fold_*_val.txt` | 每折训练与验证文件清单 |
| `data/split_summary.json` | 折容量、类别出现和像素统计 |

图像均1024×1024、RGB；mask同尺寸、单通道L、原始ID0..8。默认Fold0验证，Fold1..4训练；Fold0为5596/1400，其余四折各为5597/1399。

当前配对核验通过，训练/验证文件名交集为0。目录使用原始图像的硬链接，必须只读，不能覆盖或重新编码PNG。Examples的11对样本与训练0000..0010重复，没有作为额外数据加入。

## 2. 标签、Ignore与类别分布

下列像素比例来自已记录的默认划分统计，占各划分全部像素的比例，不是类别IoU。

| 官方ID | 类别 | 训练像素比例 | 验证像素比例 | 参与mIoU |
|---:|---|---:|---:|---|
| 0 | Ignore（忽略） | 1.3776% | 1.2805% | 否 |
| 1 | Background（背景） | 27.5268% | 28.0447% | 是 |
| 2 | Building（建筑） | 17.9276% | 18.4313% | 是 |
| 3 | Road（道路） | 8.7240% | 9.1021% | 是 |
| 4 | Water（水体） | 6.3312% | 5.7034% | 是 |
| 5 | Barren（裸地） | 1.8155% | 1.7861% | 是 |
| 6 | Vegetation（植被） | 28.3835% | 28.4107% | 是 |
| 7 | Agricultural（农田） | 7.1504% | 6.4322% | 是 |
| 8 | Vehicle（车辆） | 0.7635% | 0.8089% | 是 |

当前工程把官方0转为255，官方1..8转为内部0..7；损失与评测使用ignore_index255。模型输出8个有效类，不是9类；导出再恢复官方1..8。不能把官方Ignore0当Background1。

各类IoU从整个验证集累计的交集/并集计算，真实Ignore像素完全排除，mIoU平均8个有效类。未出现类别的零并集处理沿用已核验的MMSeg指标口径，不自行改动。测试集没有公开mask，不能计算其真实IoU或像素类别分布。

## 3. 划分依据与风险

固定划分清单维护在项目根目录 `data_splits/`，其中 `fold_0_train.txt` 和 `fold_0_val.txt` 是默认开发划分。`prepare_data_split.py` 读取这些txt清单和官方原始数据，生成本地 `data/`，不再重新随机搜索划分。

这套清单的历史来源是：使用种子2026，从5000个候选方案中平衡折容量、各类像素量、是否出现和较大区域样本。现有划分已固定；日常复现只读取txt，不重新生成新的fold。

复核哈希：

- `data_splits/folds.csv` SHA256：`F9E5DB1FC11850A38131BB9761FB6BE2BCE9E483E17039A7E914A3791386DEE6`。
- `prepare_data_split.py` 已改为读取固定txt清单；脚本内容变化后，以Git提交记录为准。

当前没有场景ID、航带或裁剪坐标，没有按空间关系隔离切片。文件名无重叠不等于没有相邻或近重复场景泄漏；后续泛化判断仍需误差分析和适当复验。改划分或标签后必须重新核验并记录，不能继续使用旧哈希和旧实验对照。

## 4. 官方测试集1提交格式

| 项目 | 要求 |
|---|---|
| 文件数 | 500，文件名集合与输入测试图完全一致 |
| 尺寸 | 每张1024×1024，不自动缩放或裁剪 |
| 格式 | PNG、uint8、单通道灰度，Pillow模式L |
| PNG IHDR | bit depth8、color type0；禁止RGB或Palette |
| 像素值 | 官方ID0..8，不能直接保存内部0..7 |
| 名称示例 | 输入test1_1.png，输出同名test1_1.png |
| ZIP结构 | 根目录直接包含500张PNG，无多余层级或额外文件 |

预测目录可以同时保留PNG和ZIP，但提交ZIP内部只能打入PNG。检查数量、文件名、尺寸、通道、位深、标签及压缩包完整性后再提交。生成ZIP并不证明精度或赛规全部正确。

本规范与历史统计来自官方Label.txt、赛题PDF、folds.csv、split_summary和已完成的数量/配对/图像格式核验；实际服务器上传副本仍需按setup执行完整性检查。
